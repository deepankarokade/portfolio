# Deepankar Rokade — Portfolio

A responsive, static developer portfolio based on the supplied dark-grid reference. Content is sourced from the attached resume.

## Preview locally

Open `index.html` in a browser. For a local server, run one of:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000` from this folder.

## Deploy

This is a static site and does not require a backend or build step. Deploy the folder using Vercel, Netlify, GitHub Pages, or another static host. For Vercel, import the repository and use the default static deployment settings.

## Before publishing

- Verify the LinkedIn URL in `index.html`.
- Add the public repository URL for Ledger API if you want it linked; the resume did not provide one, so no repository link is fabricated.
- Optional: add a downloadable resume file and link it from the hero.
- Review the contact details before publishing them publicly.

## Stack

HTML, CSS, JavaScript, Google Fonts (DM Sans and Space Grotesk). No runtime framework, server, database, or build command is required.
